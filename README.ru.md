# 🌓 Theme Flip

**Превращает любую тему SillyTavern из тёмной в светлую (и обратно) одним кликом, сохраняя её характер, а потом окрашивает весь интерфейс в любой цвет.**

Выбери тему, которая нравится, нажми кнопку и получи такую же, но светлую (или наоборот). Двинь ползунок, и весь интерфейс уйдёт в зелёный, голубой или персиковый, даже если тема прописывает цвета жёстко в Custom CSS.

---

## ✨ Возможности

| | |
|---|---|
| 🌗 **Тёмная ⇄ светлая** | Один клик в меню волшебной палочки или в панели. Работает в обе стороны и сохраняет оттенок: тёмно-синяя тема становится нежно-голубой. |
| 🎨 **Тинт** | Шесть цветных кружков или любой свой цвет и ползунок силы. Уводит к этому цвету *всё*, в том числе цвета, которые в исходной теме «застряли» красными или розовыми. |
| 🎚️ **Тонкая настройка** | Ползунки насыщенности и яркости фона с живым предпросмотром. |
| 👀 **Превью до / после** | Мини-чат в панели показывает исходные цвета рядом с результатом. Сама панель красится в цвета *твоей текущей* темы. |
| 💾 **Пресеты** | Сохраняй рецепт (до 30) и применяй в один клик. Пресет весит около 65 байт: хранятся настройки, а не копия темы. |
| 📤 **Экспорт / импорт** | Делись пресетами в крошечном `.json`-файле. Пресет подходит к любой теме. |
| ⏰ **Авто-режим** | Следует за системной светлой/тёмной темой или переключается по времени суток. |
| 🌊 **Плавный переход** | Тема перетекает, а не мигает. |
| 🌍 **Русский и английский интерфейс** | Язык берётся из настроек SillyTavern. |
| 🔒 **Ничего не ломает** | Файл темы не меняется. Выключил, и всё как было. Сетевых запросов нет, всё хранится в твоём браузере. |

## 📦 Установка

**Через GitHub (удобнее всего)**, когда репозиторий опубликован:

1. В SillyTavern открой **Extensions → Install extension**.
2. Вставь ссылку на репозиторий и подтверди.
3. Перезагрузи страницу.

**Вручную:**

1. Скопируй папку `theme-flip` (в ней должны лежать `manifest.json`, `index.js`, `style.css`) в
   `SillyTavern/data/<твой-пользователь>/extensions/` (обычно `default-user`).
2. Перезагрузи Таверну с очисткой кэша (**Ctrl+F5**): скрипты расширений кэшируются.

Что появится:

- пункт **«Светлая / тёмная тема»** в меню волшебной палочки (🪄) рядом с полем ввода;
- панель **Theme Flip** в настройках **Extensions**.

---

## 🚀 Быстрый старт

1. Нажми **«Светлая / тёмная тема»** в меню палочки, и тема перевернётся.
2. Открой панель **Theme Flip**. Выбери кружок **тинта**, чтобы уйти всем интерфейсом к цвету.
3. Подкрути **насыщенность** и **яркость фона**, пока не понравится.
4. Введи название и нажми **«Сохранить»**: получится пресет.

## 🧭 Панель по пунктам

| Элемент | Что делает |
|---|---|
| **Светлая / Тёмная** | Какой вид ты хочешь видеть. Если выбрать вид, противоположный родному виду темы, она перевернётся. |
| **До / после** | Живое превью на реальных цветах твоей темы. |
| **Тинт** | Выбери кружок (радужный кружок даёт любой цвет, перечёркнутый выключает тинт). Ползунок задаёт силу: примерно с 35% оттенок полностью следует за тинтом, а дальше цвета становятся насыщеннее. |
| **Насыщенность** | Делает все цвета приглушённее или ярче. |
| **Яркость фона** | Сдвигает панели и пузыри сообщений светлее или темнее. |
| **Авто-режим** | *Вручную*, *Система* (следует за светлой/тёмной темой ОС) или *По времени* (задаёшь, когда начинается и заканчивается «светлая»). Кнопка в меню палочки отключает авто-режим. |
| **Пресеты** | Сохрани текущий вид, нажми на кружок-пресет, чтобы применить, ✕ удаляет. **Экспорт** скачивает все пресеты, **Импорт** добавляет их из файла. |
| **Менять тёмная ⇄ светлая** | Сними галочку, чтобы использовать только тинт, насыщенность и яркость, не меняя светлость самой темы. |
| **Сбросить** | Сбрасывает ползунки и тинт. Сохранённые пресеты остаются. |

## 🧪 Пресеты и обмен

Пресет — это крошечный рецепт. Вот как выглядит экспортированный файл:

```json
{
  "themeFlip": 1,
  "presets": [
    { "n": "Мятная светлая", "m": "l", "t": "#8fe0c4", "a": 80, "s": 100, "b": 0 }
  ]
}
```

| Ключ | Значение |
|---|---|
| `n` | название (до 30 символов) |
| `m` | `"l"` светлая, `"d"` тёмная |
| `t` | цвет тинта (`""` = без тинта) |
| `a` | сила тинта, 0–100 |
| `s` | насыщенность, 30–160 (%) |
| `b` | яркость фона, от −10 до 6 |

Режим хранится как *желаемый вид*, поэтому «светлая с мятным тинтом» даёт светлую мятную тему и из тёмной, и из светлой исходной. Импортируемые файлы проверяются: лишние ключи игнорируются, числа вне допустимого диапазона ограничиваются.

## ⚙️ Как это работает

Theme Flip не редактирует твою тему. Он накладывает тонкий слой стилей сверху и снимает его при выключении:

1. **Переменные темы**: пересчитываются цветовые переменные `--SmartTheme*` из SillyTavern.
2. **Custom CSS**: цвета, прописанные в Custom CSS темы (hex, rgb, hsl, в том числе собственные переменные и градиенты), читаются и пересчитываются по ролям: фоны, текст, акценты, рамки, тени.
3. **Содержимое чата**: блоки `<style>` и цвета в `style="..."` внутри сообщений тоже обрабатываются, включая новые сообщения по мере появления.
4. **Фон страницы**: если нет настоящей фоновой картинки, перекрашивается и страница за полупрозрачными панелями, поэтому панели не становятся серыми.

Цвета сопоставляются с ролями по свойству и яркости, а затем пересчитываются через HSL, чтобы сохранить оттенок. Картинки и графика в `url(...)` не затрагиваются.

## ❓ FAQ и ограничения

**Что-то осталось прежнего цвета.** Цвета, «запечённые» в картинки, или заданные там, куда расширение не может заглянуть (например, собственные стили другого расширения), остаются как есть. При включённом **тинте** почти все цвета темы и чата уводятся к нему, так что попробуй увеличить его силу.

**Фоновая картинка, которую я поставила, не изменилась.** Так и задумано: настоящие фоновые картинки расширение не трогает.

**Слишком бледно / слишком ярко.** Используй ползунки насыщенности и фона. Значения по умолчанию лежат в блоке `TUNE` в начале `index.js`.

**Тормозит ли это?** Тема обрабатывается один раз при изменении. Содержимое чата обрабатывается инкрементально: смотрятся только *новые* сообщения (не чаще раза в 250 мс), уже проверенные элементы повторно не читаются, а пока ты двигаешь ползунок, чат обновляется только после остановки. Если в очень длинном чате всё равно заметны лаги, сними галочку **«Перекрашивать содержимое чата»** в панели: тема и Custom CSS продолжат работать, не будут перекрашиваться только цвета, написанные прямо внутри сообщений.

**Где хранятся данные?** В `localStorage` твоего браузера (`themeFlip_settings`, `themeFlip_presets`, `themeFlip_light`). Никуда ничего не отправляется.

**Как удалить полностью?** Удали папку расширения и при желании очисть эти три ключа `localStorage`.

**Отладка.** В консоли браузера: `themeFlip.refresh()` применяет всё заново.

Разработано и проверено на SillyTavern 1.19.0. Плавный переход использует View Transitions API там, где браузер его поддерживает, и обычное затухание в остальных случаях.
